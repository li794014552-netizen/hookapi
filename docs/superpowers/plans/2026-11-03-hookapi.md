# HookAPI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an installable FastAPI package that receives HMAC-SHA256–signed webhooks, stores events in SQLite, and replays original bodies to a configured downstream URL.

**Architecture:** Config (Pydantic) → verify (HMAC) → store (SQLite) → forward (httpx) → FastAPI routes; pytest with TestClient and mocked downstream HTTP.

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, pydantic v2, httpx, pyyaml, pytest

## Global Constraints

- Repo root: `/workspace/hookapi`
- Package / import name: `hookapi`
- No Playwright/Selenium
- Unit tests must pass offline (TestClient + mock httpx)
- English README (Upwork portfolio)
- Secrets only via config `${ENV}` or env; never commit real tokens
- Signature header: `X-Hookapi-Signature: sha256=<lowercase hex>` (HMAC-SHA256 of raw body)

### Task 2: Verify + SQLite store

**Files:**
- Create: `hookapi/verify.py`, `hookapi/store.py`
- Test: `tests/test_verify.py`, `tests/test_store.py`

**Interfaces:**
- Consumes: `AppConfig` (store uses path)
- Produces:
  - `compute_signature(secret: str, body: bytes) -> str` → lowercase hex digest
  - `parse_signature_header(header: str | None) -> str | None` → hex if `sha256=<hex>` else None
  - `signatures_match(expected_hex: str, provided_hex: str) -> bool` (constant-time)
  - `EventStore(path)` with `insert(source, body: bytes, headers: dict) -> Event`, `get(id) -> Event | None`, `list_events(*, source: str | None = None, limit: int = 50) -> list[Event]`, `update_replay(id, status: str, detail: str | None) -> None`
  - `Event` dataclass: `id: str`, `source: str`, `received_at: str`, `body: bytes`, `headers: dict[str, str]`, `replay_status: str`, `replay_detail: str | None`

### Task 3: Forward + FastAPI routes

**Files:**
- Create: `hookapi/forward.py`, `hookapi/api.py`
- Test: `tests/test_forward.py`, `tests/test_api.py`

**Interfaces:**
- Consumes: `AppConfig`, verify helpers, `EventStore`
- Produces:
  - `forward_raw(url: str, body: bytes, *, content_type: str | None = None) -> tuple[int, str]` — POST body; return status_code and response text (or error string); raises `httpx.HTTPError` on transport failure after raise_for_status optional — prefer returning `(status, text)` for non-2xx without raising, and raise/return clearly documented for connection errors (tests mock httpx)
  - `create_app(config: AppConfig) -> FastAPI` with routes from design:
    - `POST /hooks/{source}` — raw body; header `X-Hookapi-Signature`; 401 on fail; 201 with id
    - `GET /events`, `GET /events/{id}`
    - `POST /events/{id}/replay` — uses `config.forward_url`; 400 if unset; updates replay status
